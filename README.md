# Дневник малыша

PWA для молодых родителей: сон, бодрствование, кормления (грудь с таймером по сторонам, бутылочка, прикорм), подгузники, температура, вес и заметки. Всё видно на 24-часовом циферблате, сводка за сутки сравнивается с нормами по возрасту.

Открыть: https://safarovfarukh1.github.io/baby/

## Установка на iPhone
Safari → открыть ссылку → «Поделиться» → «На экран „Домой“».

## Данные
Записи хранятся только на устройстве (localStorage). В профиле есть резервная копия: сохранить в файл и загрузить обратно.

## Нормы
- Сон за сутки — AASM (с 4 месяцев), для младших — сводные рекомендации.
- Смесь — AAP: около 165 мл на кг веса в сутки, не больше 960 мл.
- Окна бодрствования — сводные таблицы, показаны диапазоном.

Ориентиры, не диагноз.

## Файлы
- `index.html`, `style.css`, `app.js` — приложение
- `sw.js` — офлайн-кэш (при изменениях поднимать `VERSION`)
- `manifest.webmanifest`, `icons/` — установка на экран
